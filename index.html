Follow Alert – setup needed

Twitch only gives follow events to logged-in apps, so this overlay needs a Client ID and a user token from you (one-time setup):

  1. Go to dev.twitch.tv/console → Register Your Application. Redirect URL: http://localhost. Category: Other. Copy the Client ID.
  2. Open this link in your browser (replace YOUR_CLIENT_ID), logged in as the channel owner:
    https://id.twitch.tv/oauth2/authorize?client_id=YOUR_CLIENT_ID&redirect_uri=http://localhost&response_type=token&scope=moderator:read:followers
  3. Click Authorize. The page fails to load – that's fine. Copy the value after access_token= from the address bar (up to the next &).
  4. Use it either in the URL: twitch-follow-alert.html?clientId=…&token=…
    or put both into CLIENT_ID / TOKEN at the top of the script (best for "Local file" in OBS).

Add ?test=1 (or press T) to preview an alert without a real follow.
Keep your token private – don't show the OBS source properties on stream.
